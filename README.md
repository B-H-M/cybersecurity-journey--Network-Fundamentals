## 📚 Course Summary

### 1. Introduction to Network Fundamentals

Developed a foundational understanding of computer networking, including how devices communicate, exchange data, and connect through different network infrastructures.

**SOC relevance:** Understanding normal network communication helps analysts recognize abnormal traffic patterns and potential security threats.

### 2. Types of Networks

Explored different network classifications, including:

- **LAN:** Local Area Network
- **WAN:** Wide Area Network
- **MAN:** Metropolitan Area Network
- **PAN:** Personal Area Network
- **WLAN:** Wireless Local Area Network

**SOC relevance:** Understanding network boundaries helps identify potential entry points, network exposure, and security risks.

### 3. Network Topologies

Studied common network topologies, including Star, Bus, Ring, Mesh, and Tree.

Learned how network structure affects connectivity, performance, fault tolerance, and troubleshooting.

**SOC relevance:** Network topology knowledge supports the identification of vulnerable network segments and potential attack paths.

### 4. OSI Reference Model

Explored the seven layers of the OSI model and their roles in network communication.

| Layer | Name | Primary Function |
|---|---|---|
| 7 | Application | Network services and applications |
| 6 | Presentation | Data formatting and encryption |
| 5 | Session | Session management |
| 4 | Transport | End-to-end data delivery |
| 3 | Network | IP addressing and routing |
| 2 | Data Link | MAC addressing and frames |
| 1 | Physical | Physical transmission of bits |

**SOC relevance:** The OSI model provides a structured approach to analyzing network traffic and troubleshooting security incidents.

### 5. Network Devices

Strengthened my understanding of networking equipment, including routers, switches, hubs, firewalls, wireless access points, and modems.

**SOC relevance:** Understanding device functions helps with network monitoring, traffic analysis, and identifying potential security misconfigurations.

### 6. TCP/IP Model

Studied the four layers of the TCP/IP model and essential communication protocols, including TCP, UDP, IP, ICMP, HTTP, and DNS.

**SOC relevance:** Understanding network protocols is essential for analyzing suspicious connections, investigating unusual traffic, and interpreting network logs.

### 7. IP Addressing Mechanism

Developed knowledge of IPv4 addressing, public and private IP addresses, subnet masks, default gateways, and basic subnetting.

**SOC relevance:** IP addressing knowledge supports the identification of source and destination systems during security investigations.

### 8. Network Address Translation (NAT)

Explored how NAT translates private IP addresses into public IP addresses and supports communication between internal and external networks.

Studied the basic concepts of Static NAT, Dynamic NAT, and Port Address Translation (PAT).

**SOC relevance:** NAT knowledge helps analysts interpret network traffic and correlate external connections with internal devices.

## 🎯 Key Takeaways

My Network Fundamentals learning has reinforced several important cybersecurity principles:

- Understanding network communication is essential for effective security monitoring.
- The OSI and TCP/IP models provide a foundation for network troubleshooting and traffic analysis.
- IP addressing and subnetting are important for identifying and investigating network activity.
- Network devices, topologies, and protocols influence network security and resilience.
- Strong networking knowledge supports threat detection, incident investigation, and SOC operations.

**Most importantly, I learned that understanding how networks function is a critical first step toward understanding how to secure them.**
